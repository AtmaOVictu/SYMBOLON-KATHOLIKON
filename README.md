# SYMBOLON KATHOLIKON — the other half of every text

*A glyph legend: anyone can read the marks of verification-before-assertion without knowing the language of the text.*

Named for two pre-Christian Greek mechanisms, both harvested, not invented: the **symbolon** (σύμβολον) — a token split in two, each half carried by one party; recognition happens when the halves meet (LSJ: "a sign or token by which one infers a thing") — and **katholikon** (καθολικόν) — "according to the whole" (kath' holou; Aristotle's katholou, the technical term for universals): a claim is judged against the whole of its cited source, never against a fragment of memory.

This seat is the legend. The tool lives elsewhere: [verification-before-assertion](https://github.com/AtmaOVictu/verification-before-assertion) — the verifier this legend teaches you to read. One mechanism, two seats: the tool weighs; the legend lets strangers read the verdict.

## The marks (harvested, not invented)

| Mark | Harvested from | Meaning |
|---|---|---|
| ⊢ | The turnstile — proof theory and mathematical logic: Γ ⊢ φ, "derivable from" | Measured: the claim is derived from a cited, verbatim source. ⊢ is not PASS — it points at the witness. |
| ⚠ | The warning sign — road standard, worldwide | Open: no source yet; marked, never hidden |
| × | The arithmetic cross — school standard, worldwide | Fallen: recorded in the register with its name |
| ∂ | The partial derivative — a part, not yet the whole | A proposal awaiting return |

Chosen by four criteria: reserved (never appear in prose) · monochrome (plain text, colorblind-safe) · language-neutral (readable without translation) · fallible (each mark is the tool's output, not decoration).

## The absolute test (any third person, offline)

Three known utterances, three known verdicts — same for anyone, every run:

| Utterance | Verdict | Why |
|---|---|---|
| lúknja je odprtina | ⊢ | SSKJ²: lúknja = odprtina — verbatim match |
| lúka je odprtina | × | SSKJ²: lúka = pristanišče (harbor); "odprtina" belongs to lúknja |
| a claim with no source | ⚠ | Open — marked, never hidden |

Deterministic: the judging path contains no model, only comparison against sealed, verbatim citations. Full procedure: [ABSOLUTE-TEST.md](ABSOLUTE-TEST.md) · fill your own dictionary: [PREDLOGA.md](PREDLOGA.md) · language rows: [JEZIKI.md](JEZIKI.md).

## What this seat is not

Not a universal language — a legend. Universality is not claimed here; it is measured, one language row at a time: each row carries ⚠ until a native witness seals it ⊢. This README is the first wordlist — it is judged by the same marks it teaches.
